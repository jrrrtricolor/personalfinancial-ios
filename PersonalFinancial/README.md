# PersonalFinancial

Este diretório reunirá o código principal do app.

A estrutura interna deve começar simples:

```text
PersonalFinancial
├── App
├── Dominio
├── Importacao
├── Persistencia
├── Relatorios
├── Design
└── Watch
```

Novas divisões só devem ser criadas quando ajudarem a reduzir complexidade real.
