# PersonalFinancial iOS — Documentação Inicial

Este diretório documenta as decisões iniciais do novo projeto
`personalfinancial-ios`, que será versionado no repositório
`jrrrtricolor/personalfinancial-ios`.

O sistema atual `jrrrtricolor/PersonalFinancialSystem` será usado como
referência funcional e conceitual. O novo projeto será uma implementação
Apple-native para macOS, iPhone e Apple Watch.
